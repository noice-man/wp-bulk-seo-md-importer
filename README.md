# Bulk SEO Markdown Importer

**WordPress-плагин v1.0.0** · Автор: **Valery Molodtsov** · Проект: [ворд-пресс.рф](https://ворд-пресс.рф)

Импорт обычных записей WordPress из **одного большого `.md` / `.markdown` / `.txt`** с Yoast SEO, категориями, тегами и управлением публикацией прямо из Markdown.

**Страница плагина на ворд-пресс.рф:** [Bulk SEO Markdown Importer](https://ворд-пресс.рф/plugins/bulk-seo-markdown-importer/)  
**Установочный ZIP:** [v1.0.0](dist/wp-bulk-seo-md-importer-v1.0.0.zip)  
**Промпт для ИИ:** [docs/AI-PROMPT.md](docs/AI-PROMPT.md)  
**Пример входного файла:** [examples/example-batch.md](examples/example-batch.md)

## Установка

В WordPress откройте «Плагины → Добавить новый → Загрузить плагин», выберите ZIP и активируйте. В левом меню появится **SEO MD Импорт**.

## Процесс

1. Подготовьте общий MD (можно использовать `docs/AI-PROMPT.md`). Пример — `examples/example-batch.md`.
2. Загрузите файл в **SEO MD Импорт → Проверить и показать предпросмотр**.
3. Сверьте количество, ошибки и карточки записей. Кнопки «Предыдущая / Следующая» и номера строк открывают любую запись, включая все поля Yoast и визуальный текст.
4. Исправьте ошибки: **при наличии хотя бы одной ошибки импорт полностью заблокирован**.
5. Отметьте подтверждение и нажмите «Выполнить импорт по файлу». Импорт идёт порциями по 10 записей с прогрессом; браузерную вкладку нужно оставить открытой до завершения. Плагин применит индивидуальный `status`/`publish_at` каждой записи, не спрашивая общий режим.

## Статусы из Markdown

| Значение | Результат |
|---|---|
| `status: draft` без `publish_at` | Черновик |
| `status: publish` без `publish_at` | Немедленная публикация |
| `publish_at: 2030-01-15 10:30` | Запланированная публикация (если дата на момент импорта будущая) |
| `status: draft` + `publish_at` | Ошибка валидации |
| Не указан ни `status`, ни `publish_at` | Ошибка валидации |

Все даты — **часовой пояс WordPress**, а не обязательно часовой пояс браузера. Отложенные публикации выполняет WP-Cron; для точного времени лучше настроить системный cron.

## Формат

Каждый материал начинается со строки `<!-- WPSEO:POST -->`, затем поля между `---` и `---`, далее тело статьи. До 10 МБ и 300 записей на один файл. UTF-8.

Минимальные поля: `title`, `slug`, `yoast_title`, `yoast_meta_description`, `yoast_focus_keyphrase`, `status` или `publish_at`, непустой текст.

Дополнительно: `excerpt`, `categories`, `tags`, `featured_image_id`, канонический URL, breadcrumbs, Open Graph, Twitter/X, robots, cornerstone, schema и первичная категория Yoast. Подробности и полный пример — в `docs/AI-PROMPT.md` и `examples/example-batch.md`.

- Категории и метки будут созданы при отсутствии, затем назначены записи.
- Изображение записи можно назначить только по **ID существующего изображения из медиатеки**. Внешние изображения по URL автоматически не загружаются.
- SEO-поля Yoast сохраняются как postmeta. Результаты SEO-анализа (цветные индикаторы и баллы) не импортируются и могут пересчитываться плагином Yoast отдельно.
- Если запись с таким `slug` уже существует, **она пропускается**; существующий контент не перезаписывается.
- Все записи первоначально создаются как черновики и получают метаполя, затем переводятся в указанный статус, чтобы не публиковать пустые SEO-метаданные.
- Изображения и URL отфильтровываются средствами WordPress; исполняемый HTML/JS из Markdown не импортируется.

## Ограничения и безопасность

- Для обычных записей типа `post`; не для страниц или CPT.
- Для доступа нужны права администратора (`manage_options`) и право публикации (`publish_posts`). Файл и импорт подтверждаются nonce, перед подтверждением проверяется хеш временного файла.
- После загрузки временный файл живёт до 45 минут в системной временной папке; после импорта удаляется. При повторной загрузке предыдущий файл удаляется.
- Рендерер Markdown поддерживает заголовки, абзацы, списки, цитаты, ссылки, inline-code, блоки кода и отдельные изображения по URL. **Не поддерживает таблицы, вложенные списки, сноски и произвольный HTML.** Перед массовым применением протестируйте на нескольких записях.
- Поддержка метаполей Yoast основана на соглашениях имён полей текущих версий Yoast SEO; наличие SEO-метаполей не гарантирует оценку Yoast или попадание в индекс.
- Не используйте одновременно два импорта из одной админ-учётной записи: хранится одна активная сессия предпросмотра.
- Публикация или создание таксономий может закончиться частично при неожиданной ошибке БД; отчёт показывает успешные и проблемные записи. Повторная загрузка с теми же slug пропускает существующие записи.
