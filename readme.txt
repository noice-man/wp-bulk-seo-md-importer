Массовый импорт записей WordPress из одного Markdown-файла с метаданными Yoast SEO и индивидуальным расписанием.

== Description ==

Загрузите общий Markdown-файл, проверьте количество и поля каждой записи, затем подтвердите импорт.

- Предпросмотр и валидация до импорта.
- Поддержка SEO Title, meta description, focus keyphrase и дополнительных полей Yoast.
- Черновик, немедленная или отложенная публикация задаются в каждой записи MD.
- Категории, метки и ID изображения.
- Обработка порциями по 10 записей.

Проект: https://ворд-пресс.рф/plugins/bulk-seo-markdown-importer/ (после публикации карточки).
Исходники: https://github.com/noice-man/wp-bulk-seo-md-importer

== Installation ==

Установите ZIP в Плагины → Добавить новый → Загрузить плагин. После активации откройте «SEO MD Импорт» в левом меню.
