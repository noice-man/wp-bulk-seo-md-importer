# История изменений

## 1.0.0 — 2026-10-10

- Импорт до 300 обычных записей WordPress из одного файла Markdown до 10 МБ.
- Валидатор front matter и предпросмотр всех записей до импорта.
- Переход по номерам записей, кнопки «Предыдущая» и «Следующая».
- Индивидуальные правила: черновик, немедленная публикация и будущая дата из MD.
- Импорт метаполей Yoast SEO, категорий, меток и ID изображения.
- Порционный импорт по 10 записей и защита от повторного создания одного slug.
- Отдельный промпт для ИИ и пример MD с тремя режимами.

Проверено локальными тестами. Реальное внедрение требует проверки на тестовом WordPress.
